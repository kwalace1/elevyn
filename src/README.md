# src — Elevyn Surface

Projector-facing OS UI. Speaks to the brain over HTTP. Never executes system commands directly.

- `components/` — shell, orb, rails, glass, mic
- `services/api` — brain client
- `services/voice` — STT/TTS abstractions (browser now, local models later)
- `hooks/` — interaction loop + live data
- `types/` — shared domain vocabulary
- `styles/` — design tokens
